    Playing together

    iCarrot is built for a squad of three. One player hosts; the others join them. The host plays too: their copy of the game is the server. Builds that run in a web browser can join a desktop host.

    Each player gets their own carrot colour: orange for the first, purple for the second, and so on.

    Joining

    Players join on the title screen, while the stars are out. Each one who joins drops onto the cliff next to the others. When the host starts, the whole squad walks out and leaps into the level together. Once the walkout has started the door is shut: anyone joining later is turned away for now.

    If the host leaves, everyone else keeps playing on their own.

    Who runs what

    Co-op games have to decide which machine is in charge of each thing. iCarrot splits it so that your own actions always feel instant:

    What Run by Everyone else
    Your carrot (moving, jumping, dashing, aiming) You Follows your streamed position
    Your bullets hitting enemies You (you report the hit) Sees the hit and its number
    Enemy attacks hitting you You Sees your damage number
    Enemies: their AI, movement, health and deaths The host Follows the host's stream
    Player slots, the title sequence, restarts The host
    Goo, sparks, casings, flinches, sounds Every machine

    Big enemy moments (a zombie starting a slap, a potato slamming a wall) are announced by the host and played on every machine at once. Each machine then checks its own carrot against them.

    Enemies chase the nearest standing carrot, whoever's it is. Every player's camera follows their own carrot (see Camera).

    Wiping and restarting

    When every carrot in the squad is knocked out (see Health), "SQUAD WIPED" comes up. After 3.5 s the host restarts the level for everyone.

    Pausing

    Any player can pause, and it freezes the game for the whole squad. See Pause.

    Tunable parameters

    These are read straight from the game's files, so they are always the current values. Open the file in the Godot Inspector to change them.
