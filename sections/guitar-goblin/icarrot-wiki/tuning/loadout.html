    styles/loadout.tres

    The guns every carrot carries into a level, in the order the number keys pick them (1, 2, 3...) and Q cycles them. Lives in styles/loadout.tres; drag a Weapon from styles/weapons/ in or out to change it. (Weapon.all() is still every gun the game knows, in network order; the loadout only picks which of them you hold.)

    Open this file in the Godot Inspector to change these values. While the game runs from the editor, most of them can also be changed live through the Remote scene tree.

    Its fields are defined in scripts/loadout.gd.

    weaponsArray[Resource]([ExtResource("2"), ExtResource("3"), ExtResource("4")]) script default []The equipped guns, in number-key order.
