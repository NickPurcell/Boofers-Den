    styles/weapons/rocket_launcher.tres

    One gun: how it handles, how its damage falls off with range, and how it looks and sounds. Each lives in styles/weapons/ as a .tres you can tune in the Inspector (every number is a slider; "or_greater" sliders accept typed values past their end). While the game runs from the editor, edit the .tres live and the next shot uses the new numbers. Weapon.all() lists them in the order the number keys pick them.

    Described on: Rocket Launcher

    Open this file in the Godot Inspector to change these values. While the game runs from the editor, most of them can also be changed live through the Remote scene tree.

    Its fields are defined in scripts/weapon.gd.
