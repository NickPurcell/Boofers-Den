    styles/ammo_drops.tres

    Destiny-style ammo bricks: every enemy that dies may drop a special (green) or heavy (purple) brick, at most one per kill. The host rolls each drop and tells every machine; each player gets their own copy that only they can pick up, so partners never fight over ammo. Lives in styles/ammo_drops.tres; every number is a slider.

    Described on: Ammo

    Open this file in the Godot Inspector to change these values. While the game runs from the editor, most of them can also be changed live through the Remote scene tree.

    Its fields are defined in scripts/ammo_drops.gd.

    ParameterValueRangeWhat it does
