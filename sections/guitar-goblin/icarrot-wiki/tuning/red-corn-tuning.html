    styles/red_corn_tuning.tres

    Feel knobs for the carrots (movement, double jump, dash). Shared by every player via tuning.tres. While the game runs from the editor, select a carrot in the Remote scene tree to edit these live.

    Open this file in the Godot Inspector to change these values. While the game runs from the editor, most of them can also be changed live through the Remote scene tree.

    Its fields are defined in scripts/tuning.gd.
