    styles/zombie.tres

    A carrot's colours. Each player slot gets one (see styles/). Edit the .tres files to recolour.

    Described on: Zombie

    Open this file in the Godot Inspector to change these values. While the game runs from the editor, most of them can also be changed live through the Remote scene tree.

    Its fields are defined in scripts/carrot_style.gd.
