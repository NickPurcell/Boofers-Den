    styles/title_timing.tres

    Timing knobs for the title sequence (scripts/title.gd), shared by every machine via styles/title_timing.tres. Edit it in the Inspector and save, then press R in a running debug game: the title reloads with the new numbers (the host's R replays it for everyone). Or, while running from the editor, select Title in the Remote scene tree and edit its timing live.

    Open this file in the Godot Inspector to change these values. While the game runs from the editor, most of them can also be changed live through the Remote scene tree.

    Its fields are defined in scripts/title_timing.gd.
