# HoloTable against SW5e: what a table needs, and what is there

**What this describes.** HoloTable in NickPurcell/Boofers-Den, `main` at commit **4427cbe** (17 Nov 2026, 08:01 PST): the client in `sections/jpesus/holotable/` (app.js, books.js, rules.js, importer.js, packs.js, themes.js, index.html, style.css, README.md), the server in `api/holotable.js`, `api/_holotable-game.js`, `_holotable-store.js` and `_holotable-sw5e-data.js`, and `tests/holotable-api.test.js`. The audit was written against 7b5f7c0. The two commits since then (91c959c, scene-change screen wipes; 4427cbe, GM-scripted scene movements for tokens and props) change the state of no line below.

**Updated 17 Nov 2026** for what landed on `main` after the audit: the combat view (#89, #94, #97, #102, and the variants with this update), the stat-block rolls (#96) and the encounter meter (#100). Each changed line says so ("Since 17 Nov"). Everything else is still as it was at 4427cbe.

**Updated again on the evening of 17 Nov 2026** for what landed on `main` since: class resources on the sheet (#108) and in the combat view, Extra Attack, two-weapon fighting, grapple, shove and help, maneuvers, Action Surge, and fighting styles (lines 3.x, 5.8, 5.9, and the new 8.16 and 8.17), minimum roll thresholds (12.2), the sheet's AC, proficiency, misc bonuses, temporary points and size (5.3–5.6, 5.12, 5.13, 4.9), casting (3.13, 3.14, 4.4–4.7, the new 4.11), the guided build and backgrounds (1.3, 1.4, 1.7, 1.8, 2.7), multiclassing and undoing a level (2.12, 2.13, 2.15), the party stash and loot (6.9, 9.10), the GM's tools and table rules (8.13–8.15, 9.8, 9.9, 9.12, 9.17, 9.18, 12.4–12.6), between-fights play (11.3–11.6), and starships (section 10). Each line says which pull request did it. 5.9 is corrected: SW5e has no flat +2 fighting style.

**How it was checked.**
- HoloTable: every line of the files above was read at 7b5f7c0, and the diffs of the two later commits were checked for anything that touches a line here. The test suite was run locally: 42 of 42 pass at 7b5f7c0, 43 of 43 at 91c959c, 45 of 45 at 4427cbe. Line numbers below are at 4427cbe. The live site was not opened (it is behind two passwords this audit did not use), so nothing here says what the live game currently holds.
- SW5e: from SW5e's own public data (sw5eapi.azurewebsites.net), fetched for this audit: the class tables (`class`), archetypes (`archetype`), creatures (`monster`), size data (`starshipBaseSize`), and the chapter lists of the Player's Handbook (`playerHandbookRule`), Starships of the Galaxy (`starshipRule`), Wretched Hives (`wretchedHivesRule`), the Expanded Content (`expandedContent`) and the Variant Rules (`variantRule`).
- SW5e's API reports one data version for everything it serves: version 199, last updated 6 May 2023. HoloTable's pickers and library show that build, so anything sw5e.com changed later is not in them.
- A fuller inventory of SW5e's data was built for this audit (`sw5e-inventory.md`, kept with it). Every count quoted below from that inventory was re-checked against the API before use.
- A line marked *(inferred)* is a judgement not read directly from code or from SW5e's data.

**How to read a line.** Each line can be ticked off on its own:

`ID · STATE · HOW · MATTERS — what the rules need. What HoloTable does. Evidence.`

- **STATE**: DONE (works as the rules ask), PARTIAL (some of it), MISSING (no code for it).
- **HOW**: *computes* (HoloTable does the rule's arithmetic or enforces it) · *stores* (keeps what a person types; no arithmetic, no check) · *text* (shows or copies the rule's words; nothing is applied) · *none* (no code).
- **MATTERS**: *every session* · *sometimes* · *nicety*. "Every session (for X)" means every session for a table that has an X in it.

DONE lines are ticked `[x]`; PARTIAL and MISSING are open `[ ]`.

## 1. Making a character (level 1)

- [x] **1.1 · DONE · computes · sometimes** — Bring in a character built on sw5e.com. HoloTable imports the builder's Roll20 export and its character JSON, and Foundry (sw5e) actors; re-importing updates the sheet and keeps photos, current HP and points used. Evidence: `importAny`, `fromRoll20`, `fromSw5eBuilder`, `fromFoundry` (importer.js:28–297); `importText` (app.js:324).
- [ ] **1.2 · PARTIAL · computes · sometimes** — Import fidelity. The builder's character JSON carries no power levels (every power arrives as level 0), AC is set to 10 + Dex unless the export overrides it, HP is recomputed, saving throws come from the first class only, and custom weapons default to 1d6 Str. The importer lists these as notes for the player to check, but each is a wrong number until fixed by hand. Evidence: importer.js:165–216, 225.
- [x] **1.3 · DONE · computes · sometimes** — A guided level-1 build in the table itself (species, class, ability scores, background, equipment, in that order). "＋ New character" makes a blank level-1 Fighter with 10 HP and every score 10; the level-up wizard only starts at level 2. Evidence: `blankCharacter` (rules.js:198); `newCharBtn` (app.js:264). **Since 17 Nov:** "＋ New" walks through SW5e's own steps: species, class (with its skill choices), ability scores, background (two skills, one feat) and equipment, and nothing is saved until the end (#171).
- [x] **1.4 · DONE · computes · sometimes** — Ability score generation: the PHB's standard array, point buy and rolled scores, assigned to abilities. Only `/r 4d6dl1` in chat; scores are typed. Evidence: no code; abilities are number inputs in `renderSheet` (app.js:380). **Since 17 Nov:** a 🎲 Ability scores… dialog sets all six from the standard set, six server rolls of 4d6 (highest three, in chat), or SW5e's 27-point buy (#166).
- [ ] **1.5 · PARTIAL · text · sometimes** — Species: traits, speed, languages, size and the ability increase. The ◈ picker adds each trait as a feature, sets walking speed, appends languages, and applies the increase only when it is one fixed choice. Size, senses (darkvision etc.), resistances and other movement speeds are not set anywhere on the sheet. Evidence: `openSpeciesPicker` (books.js:189); `fixedAsi` (_holotable-sw5e-data.js:23).
- [ ] **1.6 · MISSING · none · sometimes** — Species whose increase is a choice ("any one", or one of several options): let the player pick. Today the player types the new scores. Evidence: `fixedAsi` returns null for choices (_holotable-sw5e-data.js:23).
- [x] **1.7 · DONE · computes · sometimes** — Class at level 1: hit points at 1st level (the die's maximum + Con), the class's two saving throw proficiencies, armor/weapon/tool proficiencies, and the class's skill choices (2 to 4 from a list, by class). None is set when a class is chosen by hand; save and skill dots are toggled freely with no list or count. Evidence: `blankCharacter` (rules.js:198); `save-prof` and `skill-prof` (app.js:596–597). **Since 17 Nov:** the guided build sets the class at level 1: its hit points, saves and skill choices from its own list (#171).
- [x] **1.8 · DONE · computes · sometimes** — Background: skill and tool proficiencies, languages, equipment, feature, and the background feat (the PHB's Personality and Backgrounds chapter gives backgrounds a feat; SW5e's background data lists each one's feat options). The ◈ picker writes skills and tools into the Proficiencies text box but does **not** tick the skill dots, so skill bonuses stay wrong until the player ticks them; equipment goes into Notes as text; the feat is shown only as "suggested feats" and is never added. Evidence: `openBackgroundPicker` (books.js:218–243). **Since 17 Nov:** after picking a background, the sheet asks for two skills from its list (ticked as proficiency) and one of its feats (added as a feature, with its text); the guided build uses the same step (#174). A feat's own effects are added as text, not to the numbers.
- [ ] **1.9 · MISSING · none · sometimes** — Starting equipment by class and background, or starting wealth instead. Background equipment is copied into Notes as text; class equipment is not offered. Evidence: books.js:236; no code for class equipment.
- [x] **1.10 · DONE · stores · nicety** — Personality traits, ideals, bonds, flaws, alignment, appearance, backstory, portrait and token photo. Evidence: Bio tab in `renderSheet` (app.js:544–560); `pickPhoto` (app.js:310).

## 5. The sheet's arithmetic

- [x] **5.1 · DONE · computes · every session** — Ability modifiers, saving throws, skills with proficiency and expertise, passive Perception, initiative, proficiency bonus, all recomputed live from the scores. Evidence: rules.js:134–149.

## The ten gaps that matter most

1. **Class resources (3.1–3.11).** No class's spendable numbers are tracked: rages, superiority dice, focus points, exploits, Channel the Force, Second Wind, Action Surge, Indomitable, Potent Aptitude, Kinetic Combat, Ranger's Quarry, Sage Advice and the rest. Every class has some, and they are spent every session. **Since 17 Nov:** every class's uses are tracked and its table values shown (#108). In the combat view, Rage, Sneak Attack, Force-Empowered Strikes, Double Strike, Action Surge and the Fighter's and Scholar's maneuvers do what they say. Still to come are listed on 3.2–3.10.
2. **Rests recover the wrong things (7.2–7.5).** Tech points should come back on a short rest and don't. The Consular's Force Recovery and every short-rest class use (Channel the Force, Action Surge, Second Wind and the like) aren't there, and hit dice are spent from one pool at the largest die size. **Since 17 Nov:** done (7.2–7.5).
3. **Caster numbers that are wrong today (3.12–3.14).** The Sentinel's max power level is one too low at nine of its twenty levels. The 12 archetypes that grant casting get no points. A multiclassed caster's max power level uses the wrong rule. **Since 17 Nov:** the casting archetypes and multiclass max power level are done (3.13, 3.14). The Sentinel's max power level (3.12) is still open.
4. **Measuring and areas on the map (8.4, 8.5).** There's no ruler and no cone, cube, cylinder, line or sphere template, and both are needed in every fight. **Since 17 Nov:** done in the combat view (8.4, 8.5).
5. **SW5e's own conditions, with effects and durations (7.7–7.10).** Five of SW5e's 21 conditions are missing, exhaustion follows the wrong table, and no condition changes a roll or ends on its own. **Since 17 Nov:** done (7.7–7.10).
6. **Casting beyond spending points (4.4–4.7).** Upcasting, the max power level check, concentration, and rolling a power's damage and its targets' saves are all missing. **Since 17 Nov:** upcasting, the max power level check and concentration are done from the sheet and in the combat view (4.4–4.6). A power rolls its attack, saves and damage for powers the table has data for (4.7).
7. **Attack to damage on a target (8.6, 5.10, 9.6).** You can't pick a target, roll against its AC and apply the damage with its resistances. Today the GM copies numbers from chat into the tracker. **Since 17 Nov:** done in the combat view (8.6, 5.10, 9.6).
8. **The sheet's typed numbers (5.3, 5.4, 5.5, 5.8, 5.9).** AC isn't derived from armor and shields, there's no toggle for weapon proficiency, there's no box for misc bonuses, weapon properties have no mechanics, and feature damage (rage, Sneak Attack and so on) isn't offered on rolls. **Since 17 Nov:** done: AC from armor and shields with Unarmored Defense, the proficiency toggle and the misc bonus boxes on the sheet (5.3–5.5), and weapon properties and class feature damage in the combat view (5.8, 5.9). Ammunition is on the sheet (6.6).
9. **Building and choosing (1.3, 1.7, 1.8, 2.7, 2.9).** There's no level-1 build. Background skills aren't ticked and the background feat is never added. A character past level 3 can't pick an archetype. The per-level choices (maneuvers, exploits, ideals, styles, expertise) are never asked for or counted. **Since 17 Nov:** the guided level-1 build, ability scores, backgrounds' skills and feat, and choosing a missing archetype are done (1.3, 1.4, 1.7, 1.8, 2.7).
10. **Creatures beyond hit points (9.4–9.7).** Legendary actions, recharge and per-day abilities aren't tracked, saves and skills can't be rolled, resistances aren't applied, and there's no encounter difficulty. **Since 17 Nov:** done (9.4–9.7).

## Done well

- **Server-side dice and private play.** Rolls are made on the server. GM-only rolls, whispers to a character, hidden NPCs and hidden ships are all handled, and players are never sent what they shouldn't see. The tests check this.
- **SW5e content in place.** Every book's lists are fetched by the server, cached with size caps and credited. The pickers cover powers, gear, enhanced items, species, backgrounds, feats, maneuvers, fighting styles and masteries, lightsaber forms, ventures and archetypes. The full rulebooks are searchable in the library, and the GM marks which variant rules the table uses.
- **The level-up wizard.** It runs on GM grants. It handles average, rolled or maximum HP with retroactive Con, gives ASIs at the right class levels (all ten classes checked against SW5e's tables), picks the archetype at 3 and adds each level's features.
- **Caster arithmetic for single-class Consular, Engineer, Guardian and Scout.** Point totals, max power level, point costs, and DCs and attack bonuses by alignment all match SW5e.
- **Ship arithmetic that matches Starships of the Galaxy.** Ship skills with crew proficiency, weapon attack on Wisdom and damage on Strength, and shields taking damage before hull.
- **Import from the sw5e.com builder and Foundry.** It flags what the player needs to check.
- **Saving that doesn't lose a game.** It saves on every change, keeps a backup every ten minutes of play, exports with images, restores, and never saves a blank table over a lost one.
- **Scum and Villainy at the GM's fingertips.** 271 creatures go into the tracker with tokens, HP and AC, and their attacks roll privately from the stat block.
- **Map and scenes.** Pan, zoom and pinch, Dungeondraft packs, and named scenes that switch every screen at once.
- **Tests.** 45 server tests cover security, privacy, saving and the rules engine, and all pass at 4427cbe.
