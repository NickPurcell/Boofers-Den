Minecraft in Night City

— viability study and build plan

Clawcius, 29 Sep 2026. For Nick’s PC. Offline single player, Cyberpunk 2077 patch 2.31.

Verdict Viral builds Architecture Pieces Phases Spike Limits Setup

01Verdict

VIABLE

Viable. No hard blocker stands between us and the demo: first-person Steve in Night City, a creative hotbar with every item, blocks you can stand on that the path tracer lights, and creepers that Maelstrom shoots and that blow Maelstrom up. Four real limits apply (see the end). Six unknowns need a one-to-two-day spike before anything else is built.

Cyberpunk is an easier host than Elden Ring. Single player has no anti-cheat. The modding stack is mature: CET, RED4ext with Rust bindings, Codeware, TweakXL and ArchiveXL. Existing mods already spawn solid props and hostile NPCs at runtime.

02How the viral ones were built

There are three different recipes behind the clips:

  • 01 / 03

    Full rewrite (chasm’s MW2 × Skate 3 × Minecraft). All three games are AI-written Rust rewrites in one Bevy process (mashup repo, a fork of IW4L). This is the “Rust rewrite” Nick heard about: MinecraftOSS, about 131k lines traced from decompiled Java, vendored but not published separately. Its mobs only target the player. The route needs a Rust rewrite of the host game, and nobody has one for Cyberpunk, so it isn’t an option here.

  • 02 / 03

    Passthrough (chasm’s Skyrim). Real Minecraft and real Skyrim run side by side, with a mod in each: Minecraft things are passed into Skyrim’s renderer, and collision is fed back (explainer). No code is public, and the clip shows no Minecraft mobs.

  • 03 / 03

    Unknown (Tobyn Jacobs’ Elden Ring and DS1). These mod the real games and were built with a multi-agent setup around Opus 5.5 (post). The architecture hasn’t been disclosed.

Prior art for Cyberpunk: Khoner4504/mc-cyberpunk started today with a passthrough design (Paper server plus a Rust RED4ext plugin speaking the MC protocol via Azalea). So far it has only a placeholder box. We build our own; we can learn from it but won’t contribute to it.

03Architecture: hybrid passthrough

Ownership. Minecraft is authoritative for blocks, redstone, items, mob decisions and mob HP. Cyberpunk owns the terrain, its NPCs, V, and every body you see. Real Java Minecraft is the only way to get every mob, all items and full redstone (pistons included) for free, and it runs alongside path tracing on 2–4 GB and 1–2 cores.

Why a custom pipe instead of speaking the MC protocol (mc-cyberpunk’s choice). Vanilla sends mob movement only about every 150 ms. A Fabric mod can snapshot every tick (50 ms) with exactly the fields we need, and the pipe costs microseconds. Cyberpunk renders 75–100 ms behind and interpolates. Block edits are predicted locally and confirmed by the server.

Coordinates. One block is one metre, which is Cyberpunk’s unit. A fixed anchor maps the MC origin to a spot in Night City. Scope everything to one district (Watson’s Kabuki or Little China) at first.

04The pieces

Blocks are native entities, not an overlay. A block is a spawned entity with a shared cube mesh per block type (ArchiveXL, Minecraft textures upscaled so they stay crisp) and a box collider in the “World Static” layer, exactly as entSpawner already does. That gets path tracing, correct depth, DLSS and frame-gen motion vectors, and a floor V can stand on, all for free. A D3D12 overlay would lose all of that. Only exposed blocks are spawned, neighbouring solid blocks are merged into large colliders, and entities are pooled because spawning is asynchronous. Cyberpunk has no runtime mesh generation, so the budget is a few thousand visible blocks, to be measured in the spike.

Terrain goes back to Minecraft. The navmesh can’t be exported. Instead, the district’s collision is voxelized offline (WolvenKit collision export → voxelizer → invisible barrier blocks in the MC world). Near the player, a live raycast grid (roughly 256–512 rays a frame) catches cars and moved props. Mob height snaps to the ground with a downward ray.

Mobs are real Cyberpunk NPCs wearing Minecraft skins. TweakXL clones of NPC records use ArchiveXL meshes skinned to the base rig. The zombie is a fists brawler, and the skeleton is a ranged record with a bow reskin. The creeper is a script-driven puppet (move, fuse, explode) because four-legged custom rigs break when spawned. The precedent is Robot Kung-fu Bodyguards on 2.31. Mobs join a cloned “hostile to everyone except the player” attitude group so gangs and NCPD fight them, and civilians flee on their own. Minecraft decides where a mob goes; the Cyberpunk puppet follows with move commands and snaps back if it drifts more than 1.5 m.

Damage works both ways.

  • Cyberpunk → Minecraft: puppets are god-moded. A hit (OnDamageReceived) is scaled to 20 HP, sent over the pipe, and applied as Minecraft damage. When the Minecraft mob dies, Cyberpunk calls Kill().
  • Minecraft → Cyberpunk: Cyberpunk NPCs are mirrored as Carpet fake players, because creepers only target players. Minecraft cancels its own damage to them and forwards it to Cyberpunk.
  • Creepers: mob griefing is off in Minecraft, so blocks are handled by our own rule. Cyberpunk spawns the explosion (SpawnExplosionAttack), which damages NPCs and cars and never deforms the city.

The player. Steve’s first-person arms replace V’s. The held block is a fists-class item that reuses the vanilla swings. The hotbar and creative inventory are Codeware ink UI, prototyped in CET ImGui first. Input Loader adds a context so number keys and clicks don’t also fire game actions. The block outline is a wireframe-cube entity, and creative flight is a noclip mode.

Redstone comes free once blocks sync, because Minecraft runs it. We only have to render states: lit dust and torches as mesh variants, pistons as moving entities.

06Spike first: the six unknowns

  1. Does V stand reliably on runtime box colliders, and what do 2k–5k block entities cost with path tracing on?
  2. How long does an async entity spawn take, and does pooling hide it?
  3. Do hit events still fire on a god-moded NPC?
  4. Do gangs reliably fight reskinned mobs, and how bad do the animations look?
  5. Does a cloned attitude group register at runtime?
  6. What does the raycast grid cost, and does offline voxelization of a district scale?

07Hard limits

  • The navmesh is baked. Cyberpunk NPCs never walk onto your builds; mobs climbing towers has to come from Minecraft’s pathing.
  • No new first-person animation sets, only replacements, so Steve’s swing is V’s swing re-skinned.
  • NCPD heat only counts damage V deals. Police responding to a creeper has to be scripted.
  • Night City can’t be mined. The city’s own geometry stays; only placed blocks break.

08Setup on your PC

Cyberpunk 2077 2.31 (Steam or GOG) with Cyber Engine Tweaks 1.37.1, RED4ext 1.30, redscript 0.5.31, Codeware 1.20.5, TweakXL, ArchiveXL, Input Loader and WolvenKit 9.0.1. Also a Rust MSVC toolchain, Java 25, and a Fabric server for Minecraft 26.x with Carpet. Minecraft textures and the server jar are pulled from your own Minecraft install or Mojang on first run, so nothing Mojang owns ships with the mod. Stay non-commercial.

The crew can write all of the code, but it can’t run Cyberpunk: the server has no Windows or GPU. The loop is Claude Code on your PC, running at xhigh, with this plan as its brief, and you playing each milestone.
